# product-storytelling

Parte de un caso que represente al usuario real. Organiza cada capítulo alrededor de una pregunta que responderá el DEV. Muestra qué cambia para el usuario y qué condiciona su construcción. Reutiliza ejemplos y cifras trazables; marca lo que sigue siendo hipótesis.
