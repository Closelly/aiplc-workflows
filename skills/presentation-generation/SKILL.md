# presentation-generation

Escribe el briefing.json con cuatro resúmenes y tres decks. Cada slide aporta una idea, puntos legibles, notas y referencias. El comando handoff genera PowerPoint con la dirección visual aprobada. Abre los tres y revisa legibilidad y fuentes.
